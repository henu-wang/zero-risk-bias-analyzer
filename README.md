# Zero-Risk Bias Analyzer

Analyze zero-risk bias in risk elimination decisions

## Features

- Compare risk reduction vs risk elimination strategies
- Calculate cost per unit of risk reduced
- Optimal risk portfolio allocation
- Marginal safety improvement calculator
